# HANDOFF: проект @thekiramethod (как мы работаем и зачем)

Документ для нового чата (Claude Code на десктопе). Прочитай его целиком первым, потом `CLAUDE.md` (он грузится сам), потом нужный скилл из `.claude/skills/`. Дата сборки: 24 октября 2026. Всё, что здесь названо «гипотезой», не доказано нашими цифрами.

## 0. Как запустить на десктопе (для владельца)
1. `git clone https://github.com/capecode8-oss/preland.git` и `git checkout claude/schedule-5-reels-metricool-ip1tp7` (или `git pull`, если уже есть).
2. Открыть Claude Code в папке `preland`. `CLAUDE.md` и скиллы из `.claude/skills/` подхватятся сами. Хук в `.claude/settings.json` напоминает про пайплайн на каждое сообщение.
3. Подключить в Claude Code те же MCP-коннекторы, что в облаке: **VIDEO_Tool** (планирование в Videotool, brand_id 6476294) и **github**. Без них публикацию делает только владелец вручную.
4. Первое сообщение чату: «Прочитай `HANDOFF_DESKTOP.md`, `CLAUDE.md` и `.claude/skills/reel-growth-playbook/SKILL.md` (раздел 6 журнал замечаний). Скажи своими словами, зачем мы это делаем и какой у нас пайплайн. Потом жди тему.»
5. Зависимости для сборки видео и PDF: ffmpeg, Node 22+, Python 3 с `pillow numpy pymupdf pocketsphinx` (последний только для грубого распознавания речи), Chromium (Playwright). Пути в репо иногда указывают на облачные (`/usr/local/lib/python3.11/...ffmpeg...`): на десктопе использовать свой ffmpeg.

## 1. Зачем всё это (бизнес)
- Аккаунт **@thekiramethod** (Instagram, англоязычный рынок США, женщины 35–65). Героиня **Kira** это AI-персонаж («эксперт»). Решение про ярлык «AI-generated profile» за владельцем (риск для охвата, источники расходятся).
- Цель: **охват → подписчики → комментарий с кодовым словом → DM с ссылкой → покупка мини-продукта** (цифровые PDF-гайды, платёжка Lava.top). Это система продаж, а не блог.
- Что сделано к сегодня (цифры владельца из скриншотов, не проверены нами независимо): ~530 постов, ~3 258 подписчиков. Лучшие рилсы: ~730K и ~520K просмотров (B-roll с текстом про самолёт, «Never Sleep Like This On A Plane»), AI-Kira говорящая голова в travel 55.8K и 97.9K. Почти все подписчики пришли с travel B-roll. Кодовые слова: ~50 на самолётном видео, ~300 на видео про воду в джакузи круиза. **Продаж Travel Safety Guide: 3.** GLOW-ролики на старте дали ~200–250 просмотров (малая выборка, «холодный старт» новой темы).
- Главная проблема сейчас: **конверсия слово → покупка около 1%** (≈350 слов → 3 продажи). Гипотезы (не проверены): (а) воронка течёт на этапе ссылки: в репозитории `preland.html` кнопки оплаты ведут на `https://lava.top` (заглушка), живую страницу владельца я не видел; (б) люди пишут слово, ожидая бесплатное (в подписи нет цены, слово «free» запрещено); (в) интерес к travel-теме не равен намерению покупать. Нужно измерить воронку (получили DM, клик, чек, покупка), а потом решать про нишу.
- Стратегическая линия: travel и круизы **двигатель трафика**; деньги ищем в «болевой» нише женского здоровья (GLOW и новые планы) и в мостах «поездка → тело».

## 3. По какому принципу делаем контент
Источники правил: `CLAUDE.md` (главный), `reel-growth-playbook`, `reel-script-engine`.
1. **Сигналы Instagram по важности (по пересказам, не официально):** пересылки в DM (sends) на охват, сохранения, досмотр, лайки. Контент должен заставлять переслать конкретному человеку.
2. **Хук первыми 3 словами:** противоречие, угроза, узнавание. Матрица форматов #0–#8 и 5 формул (Contradiction List, Specific Audience + Dangerous Truth, Live Scene, Anti-Hook, Confession). Углы: физическая угроза телу, а не кошельку (доказано нашим 471K «Never Sleep Like This On A Plane»).
3. **Triple Loop (с Oct 23 2026):** сценарий на трёх открытых петлях любопытства: Hook (первые ~5 с), Intensifier (до ~15 с), Rehook (середина, там где падает удержание). Для 4 клипов по 10 с: клип 1 Hook+Intensifier, клип 2 первая выдача и новая петля, клип 3 Rehook, клип 4 закрытие и призыв. Подробно `reel-script-engine` раздел 2b.
4. **Язык улицы:** 8-й класс, короткие предложения (≤15 слов), без терминов. Проверка: 15-летний пересказывает суть.
5. **Факты проверяем поиском до публикации** (`references/fact-bank.md`). Нет источника, не говорим цифрой. Медицинские обещания и «лечит» запрещены. Выдуманные цитаты, «инсайдеры», отзывы запрещены. Честные оговорки обязательны.
6. **Продажа невидимая:** история → ценность → мост → призыв с кодовым словом. Призыв называет ценность и содержимое («45 situations: hotels, airports, cruise ships»), а не «a PDF».
7. **Серия** как причина подписаться; один главный призыв на ролик.
8. **Метрики недели:** охват не-подписчикам, sends/охват, слова на 1000 просмотров, покупки на 1000 просмотров. Решения по нише принимаем по этим цифрам.

## 5. Пайплайн (по умолчанию, без вопросов владельцу)
Владелец присылает тему, идею, скриншот, ссылку или рилс конкурента → сразу **готовый пакет**:
1. Суть в 5 строках: проблема, решение, совет, хук, зачем писать слово.
2. Сценарий по 4 клипам с дословной речью (16–20 слов на клип, без двоеточий и вложенных кавычек, без пауз), петли помечены.
3. 4 полных Veo-промпта (блоки HEAD, SPEECH, CAMERA, LOOK, PLACE, PERFORMANCE, TAIL повторены целиком в каждом, не «замени блок»). Анти-титры: слово «podcast» не писать, «raw unedited footage», пустой низ кадра, Negative prompt.
4. Раскадровка графики для Remotion по клипам.
5. Факты и оговорки со ссылками (из банка фактов или свежего поиска).
6. После готового видео от владельца: подпись 1700–1900 знаков (второй хук ≠ хук видео → контекст → детали → мост → CTA-блок → `📌 Save this before your next…`), проверка кадров, MP4 в `reels/`, commit и push, проверка raw URL (код 200), `createScheduledPost` (instagram, время UTC = EDT+4 до 1 ноября, потом EST+5). TikTok инструментом не поддерживается, владелец заливает вручную. Музыку в Videotool не добавляет (флаг `skip_music` не срабатывает), владелец проверяет.
Старая часть CLAUDE.md про «хуки на одобрение», аудит 12 голосов и фокус-группу 100 американцев: **это симуляция внутри чата, не данные**. Подавать одной строкой, не выдавать за исследование.

## 7. Железные запреты (из CLAUDE.md, коротко)
- Слово **«free»**, хэштеги, цена в подписи: нельзя. «Link in bio» нельзя для GLOW и CALM (био ведёт на Travel).
- Безопасная зона текста: 1080×1920, между y=270 и y=1520, ширина до 864 px.
- Fact Reel строго 5.0 с, музыка обязательна, без затухания. Talking head: оригинальный звук, музыку не добавляем.
- Карусели только на GLOW, не повторять формат в batch, факты только проверенные.
- Не публиковать без просмотра кадров. Запланированный пост нельзя править через API (только владелец вручную).
- Никаких выдуманных медицинских обещаний, цитат врачей, отзывов, счётчиков «N людей читают сейчас», обманных зачёркнутых цен. Это риск по FTC, Meta, платёжным системам.

## 8. Выученные уроки (коротко, подробно в журнале playbook)
- Veo рисует субтитры и путает слова, если реплика длинная, есть двоеточия или вложенные кавычки, или в запросе слово «podcast». Лечение: короткие фразы, один блок речи, блок «raw unedited footage», 2–4 дубля.
- Реплика должна иметь смысл и ценность: проблема, решение, совет, хук (владелец отклонял «пустые» сценарии и общие призывы вроде «I have more like this in my guide»).
- Сцена и одежда эксперта: пиджак, белая рубашка, без стетоскопа и бейджей; фон не стерильный, без текста на предметах.
- Ремейк чужого рилса: смотреть кадры плотно (1–3 кадра в секунду), выписывать КАЖДУЮ сцену с таймкодом и переносить визуальные хуки в промпты. Менять только ложные или опасные слова.
- Veo-фильтр режет «содержимое кишечника», обнажённую кожу крупным планом и давление указки на тело: формулировать нейтрально («clean model», «clay», «points without touching»), при отказе давать вариант B.
- Названия мини-продуктов должны быть любопытными и обещать механизм, который книга реально выдаёт («The Muscle Tax», «Normal Isn't Fine»). Описательные названия не конвертят (мнение владельца).

## 9. Что умеет и не умеет Claude в этой работе
- Умеет: сценарии, промпты, подписи, поиск фактов, сборка видео кодом (SVG, Three.js, Java, ffmpeg), SFX-синтез (`sfx_synth.py`), PDF-книги, разбор референсов по кадрам, планирование в Videotool, учёт.
- Не умеет: генерировать пиксели видео и голос сам; распознавать речь точно (есть только грубый pocketsphinx, плюс чтение титров с кадров); создавать реалистичные звуки (стекло, шаги); проверять живой сайт владельца и бота; видеть метрики Instagram без скриншотов.
- На десктопе (в отличие от облака) нет ограничений сети, есть GPU для 3D, можно запускать Remotion Studio с живым предпросмотром.
