# STYLE CARDS (разобрано по трём референсам владельца, Oct 2026)

## Card A. «Cutaway physics» (как работает сенсорный экран, 84 с, англ., озвучка)
- Фон почти чёрный с тёмно-синим, золотые электрические дуги, цветная полоска датчиков с цифрами (100, 81, 62, 84), палец/ручка крупно, телефон в перчатке, молекулы Na⁺/Cl⁻, интерфейс-макет (Instagram), мелкие подписи «Magnified illustration», «Values illustrative».
- Подписи сверху, по словам, белые; ключевое слово в рамке с синими «ручками» (стиль редактора).
- ~40 сцен, 1.5–2.5 с на сцену. Озвучка обязательна (структура держится на голосе).
- Реалистичность 3D (рука, перчатка): средняя; делаем стилизованно (плоско или простое 3D).

## Card B. «Low-poly counter» (How long can you hold poop?, 24 с, цикл)
- Комната: кремовая стена, бирюзовая панель, деревянный пол, окно (день → ночь), календарь с крестиками, кулер, растение. Персонаж из блоков на стуле, прозрачный торс с органами.
- Оверлей: заголовок крупным засечным шрифтом (курсив на ключевых словах), «DAYS SINCE…», счётчик с единицами (days → hours), статус-чип (See a doctor / Past normal / Normal), строка факта внизу.
- Счётчик идёт 45 дней → часы; камера наезжает и отъезжает; в конце персонаж уходит, кадр возвращается к началу (цикл).
- Озвучка не нужна, музыка. Самый лёгкий для кода стиль (Three.js + HTML-оверлей).

## Card C. «Dark-gold schematic» (схема против похмелья, 69 с, рус., озвучка)
- Палитра: почти чёрно-коричневый фон, золото (#e8b04a), красно-кораллевый для угроз, зелёный для «плюс», бежевый текст.
- Шрифты: узкий жирный гротеск для героя-числа («21», «НЕТ»), жирный Montserrat для подписей.
- Подписи внизу, 2–4 слова, ключевое слово золотым.
- Словарь сцен: узел-граф («бардак»), сетка из 21 карточки со знаками вопроса, таблица-таймлайн из трёх колонок («до / ночью / утром»), контур органа с частицами, молекулярные формулы, круговой таймер, стакан с пузырьками, баночки с этикетками, свиток с красным штампом, силуэт на фоне солнца, кнопка «Подписаться» → «Вы подписаны ✓».
- Всё плоская векторная графика: самый реалистичный стиль для кода (SVG/CSS + Chromium-захват).
- Контент-риск: в оригинале схема с добавками; у нас такое только после проверки фактов и с оговоркой.

## Что берём для ниши (женщины 35+, здоровье)
- Card B → «счётчики»: сколько можно не спать / не пить воду / сидеть; цикл, музыка.
- Card C → «схема дня»: 3-колоночная таймлайн-таблица (утро / день / вечер) для привычек; золото и тёмный фон.
- Card A → разрезы тела (мышца, кишка, кожа) плоской графикой, подписи по словам.
