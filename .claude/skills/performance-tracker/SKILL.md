# Performance Tracker
## Метрики рилсов @thekiramethod

---

## ЗАЧЕМ ТРЕКАТЬ

Каждый опубликованный рилс — это данные. Через 72 часа мы знаем:
- Какая формула работает лучше в эту неделю
- Какая тема даёт максимум пересылок
- Где hold rate падает (хук слабый) vs где watch time высокий

**DATA-FIRST RULE команды — это здесь.** Без трекинга команда работает вслепую.

## ПОРОГИ — что значат цифры

### Просмотры к 72 часам:
| Результат | Просмотры | Действие |
|-----------|-----------|---------|
| 🔥 VIRAL | 50K+ | Анализировать формулу — повторить угол |
| 🟢 STRONG | 5K–50K | Норма. Записать что сработало |
| 🟡 WEAK | 500–5K | Анализировать первые 3 слова и клип |
| 🔴 DEAD | < 500 | Urgent: понять что убило рилс |

### Sends/reach:
| Результат | % | Значение |
|-----------|---|---------|
| 🔥 VIRAL | > 3% | Цепная реакция пересылок |
| 🟢 HEALTHY | 1–2% | Нормальный шеринг |
| 🟡 LOW | 0.5–1% | Хук не триггерит желание переслать |
| 🔴 DEAD | < 0.5% | Тема или формула не работает для аудитории |

---

## АНАЛИЗ — что делать с данными

### После каждого VIRAL (50K+):
- Записать: формулу, тему, первые 3 слова, тип клипа
- Передать в команду kira-hooks как DATA-FIRST сигнал
- Попробовать похожий угол через 7+ дней

### После каждого DEAD (<500):
- Проверить: skip rate высокий? → хук слабый
- Проверить: watch time < 30%? → клип не останавливал скролл
- Проверить: sends = 0? → тема не вызвала желания переслать
- Не повторять эту формулу + тему комбинацию

### Еженедельный паттерн:
Раз в неделю — посмотреть топ-3 рилса по просмотрам:
- Какая формула повторяется? → приоритет в следующую неделю
- Какая тема повторяется? → ниша резонирует — делаем больше
