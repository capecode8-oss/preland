# KIRA Performance Tracker

## ЗАЧЕМ НУЖЕН ЭТОТ СКИЛЛ

Без данных команда работает вслепую.
Этот скилл превращает цифры из Metricool/Instagram в решения.

**Главный вопрос каждую неделю:**
> "Какие хуки принесли больше всего SHARE+SAVE — и почему?"

---

## КЛЮЧЕВЫЕ МЕТРИКИ 2026

| Метрика | Плохо | Норма | Хорошо | Вирус |
|---------|-------|-------|--------|-------|
| Просмотры | <500 | 1K-5K | 5K-50K | 100K+ |
| Skip rate | >50% | 30-50% | <30% | <20% |
| Share rate | <0.3% | 0.5-1% | 1-2% | >3% |
| Save rate | <0.5% | 1-2% | 2-5% | >8% |
| DM rate | <0.1% | 0.2-0.5% | 0.5-1% | >2% |

**Вес для алгоритма Instagram 2026:**
- DM = 3-5× вес лайка (ГЛАВНАЯ метрика)
- Save = 2× вес лайка
- Share = 2× вес лайка
- Comment = 1.5× вес лайка
- Like = 1× (меньше всего весит!)

## ЕЖЕНЕДЕЛЬНЫЙ АНАЛИЗ

### Запускать каждый понедельник (или когда просит пользователь)

**Шаг 1 — Собрать данные из Metricool/Instagram**

Попросить пользователя предоставить:
- Скриншот Instagram Insights за неделю
- Или данные из Metricool Analytics

**Шаг 2 — Найти ТОП-3 рилса**

```
ТОП по shares+saves (главный показатель):
1. [Файл] — [Views] views, [S+S] shares+saves — [Формула хука]
2. [Файл] — [Views] views, [S+S] shares+saves — [Формула хука]
3. [Файл] — [Views] views, [S+S] shares+saves — [Формула хука]
```

**Шаг 3 — Найти ПРОВАЛЫ**

```
ПРОВАЛЫ (views <500 или skip% >50%):
1. [Файл] — [Views] views — ЧТО ПОШЛО НЕ ТАК?
2. ...
```

**Шаг 4 — Паттерны**

Что объединяет ТОП-рилсы?
- Формула хука (Pattern Interrupt? Specific Loss?)
- Ниша (travel? pharmacy? money?)
- Клип (крупный план? движение?)
- День публикации?
- Время публикации?

**Шаг 5 — Рекомендации на следующую неделю**

```
ДЕЛАТЬ БОЛЬШЕ:
- Формула [X] — работает (avg views [N])
- Ниша [Y] — высокий share rate

ДЕЛАТЬ МЕНЬШЕ:
- Формула [X] — провалы
- Ниша [Y] — низкое вовлечение

ЭКСПЕРИМЕНТИРОВАТЬ:
- [Новая идея на основе данных]
```

## BENCHMARK TARGETS ДЛЯ @thekiramethod

**Текущий уровень:** 100-400 views (август 2026)

**Цели по фазам:**

| Фаза | Цель | Когда |
|------|------|-------|
| Сейчас | 1K+ views на рилс | Сентябрь 2026 |
| Рост | 5K+ views (STRONG) | Q4 2026 |
| Масштаб | 50K+ (вирус) | 2027 |

**Что нужно для 1K views:**
- Skip rate < 40%
- Хотя бы 0.5% share rate
- Хук по Pattern Interrupt или Curiosity Gap формуле

**Что нужно для 5K views (STRONG):**
- Skip rate < 30%
- 1%+ share+save rate
- Конкретная цифра или место в хуке
- Mike оценка STRONG/VIRAL ещё ДО публикации

---

## ФЛАГИ — НЕМЕДЛЕННОЕ ДЕЙСТВИЕ

Если встречаем:
- `skip% > 60%` → стоп, переосмыслить hook formula
- `DMs = 0` за неделю → проверить CTA в капшенах
- `Views < 200` на 3+ рилса подряд → SOS, нужен emergency review хуков
- `1 рилс 10× лучше остальных` → срочно скопировать формулу

## ИНТЕГРАЦИЯ С КОМАНДОЙ

Данные из Performance Tracker передаются команде:
- **Mike** использует реальные данные для прогнозов (не только инстинкт)
- **Jordan** проверяет работают ли определённые первые слова
- **Red** видит какие слабые хуки всё равно прошли (и убивает похожие)

**DATA-FIRST RULE (из kira-hooks):**
> Перед следующим batch — проверить журнал. Что сработало ПРОШЛУЮ НЕДЕЛЮ = делать больше.
