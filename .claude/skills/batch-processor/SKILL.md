# Batch Processor
## 4–6 рилсов за один сеанс · @thekiramethod

---

## КОГДА ИСПОЛЬЗОВАТЬ

Когда нужно сделать несколько рилсов подряд:
- Дневной batch: 4-5 рилсов на сегодня
- Недельный запас: 20-25 рилсов за одну сессию

**Batch-processor держит общий трек** — клипы, темы, формулы — чтобы внутри batch не было повторов.

---

## ШАГ 0 — ИНИЦИАЛИЗАЦИЯ BATCH

Перед стартом определить:

```
BATCH [дата]
Количество рилсов: [N]
Темы (если заданы): [список или "команда выбирает"]
Клипы (если заданы): [список или "footage-manager выбирает"]
Времена публикации: [список слотов]
```

Если темы не заданы → команда (Rico + Mike + VIC) выбирает автономно через Step 0 в kira-hooks.

---

## ШАГ 1 — ВЫБОР КЛИПОВ И ТЕМ ДЛЯ ВСЕГО BATCH

Перед тем как писать первый хук — определить все N клипов и тем сразу:

1. **Footage Manager**: выбрать N разных клипов (не повторять внутри batch и не брать использованные вчера)
2. **Rico**: выбрать N разных тем/углов (не повторять категорию чаще 1 раза в batch, не брать темы из последних 3 дней)
3. **Mike**: проверить что каждая тема имеет потенциал 🟢+ 

```
BATCH ПЛАН:
Рилс 1: клип [ID] | тема [X] | формула [N]
Рилс 2: клип [ID] | тема [X] | формула [N]
...
Рилс N: клип [ID] | тема [X] | формула [N]
```

Утвердить план прежде чем двигаться дальше.

---

## ШАГ 2 — КОНВЕЙЕР ДЛЯ КАЖДОГО РИЛСА

Для каждого рилса в batch — последовательно:

```
Рилс [N] / [Total]:
━━━━━━━━━━━━━━━━━━━━━━━━━━━
→ kira-hooks   : хук + аудит 11 + Veo 3 промт
→ kira-captions: капшен 1700-1900с + CTA
→ [рендер]     : python render script → MP4 + JPG превью
→ quality-check: 7 пунктов QA ✅
→ metricool-ready: push → raw URL → schedule
→ performance-tracker: добавить в журнал
━━━━━━━━━━━━━━━━━━━━━━━━━━━
✅ Рилс [N] готов → переходим к [N+1]
```

**Правило batch**: не переходить к следующему рилсу пока текущий не прошёл QA и не запланирован.

## РАСПИСАНИЕ ПУБЛИКАЦИЙ (рекомендованные слоты)

5 рилсов в день — распределять равномерно:

| Слот | Время ET | Аудитория |
|------|----------|-----------|
| 1 | 7:00 AM | утро, завтрак |
| 2 | 10:00 AM | рабочий перерыв |
| 3 | 12:30 PM | обед |
| 4 | 6:00 PM | после работы |
| 5 | 9:00 PM | прайм (Maya before sleep) |

Лучший слот для самого сильного рилса batch: **9:00 PM**.

---

## ПРАВИЛА BATCH

- ❌ Нельзя повторять клип внутри batch
- ❌ Нельзя повторять тему/нишу чаще 1 раза в batch (максимум 1 travel + 1 health + 1 money и т.д.)
- ❌ Нельзя использовать одну и ту же формулу для всех рилсов batch — ротировать
- ✅ Все 5 рилсов должны пройти QA перед тем как первый уйдёт в эфир
- ✅ Обновить footage-manager журнал после завершения batch
