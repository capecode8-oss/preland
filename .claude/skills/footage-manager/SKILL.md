## ПРАВИЛА РОТАЦИИ

1. **Никаких повторов** — клип нельзя использовать если он использовался сегодня или вчера
2. **Рандомный порядок** — перебирать библиотеку по кругу, не по порядку
3. **Распределение по нишам** — подбирать клип подходящий по настроению/теме
4. **Каждый день — минимум 4 новых клипа**

## НИШЕВОЕ СООТВЕТСТВИЕ КЛИПОВ

### ✈️ TRAVEL / AIRPORT / HOTEL
Универсальные клипы с Кирой — все подходят.
Приоритет: клипы где она в движении, на улице, в помещении.

### 💊 PHARMACY / HEALTH / MONEY
Клипы где Кира говорит в камеру, держит предмет, или на кухне.
Более близкий план = больше доверия.

### 🏠 HOME / SAFETY
Клипы в интерьере, крупный план лица = больше реакции.

### 💰 RIGHTS / CONSUMER
Клипы где Кира выглядит уверенно, смотрит в камеру.

> Пока нет нишевой разбивки по номерам — определяй по смотру кадра.

## ПОРЯДОК РАБОТЫ

### Шаг 1 — Определить какие клипы нельзя использовать
```
Сегодня: [дата]
Использованные сегодня: [список]
Использованные вчера: [список]
ЗАПРЕЩЕНО: [объединение обоих списков]
```

### Шаг 2 — Выбрать клипы для сегодняшнего batch
1. Взять все доступные клипы (полный список минус запрещённые)
2. Выбрать нужное количество рандомно (обычно 4-6)
3. Стараться не использовать более 2 клипов из одной серии подряд

### Шаг 3 — Проверить clip перед рендером
```python
FFMPEG = "/usr/local/lib/python3.11/dist-packages/imageio_ffmpeg/binaries/ffmpeg-linux-x86_64-v7.0.2"

# Проверить длительность:
ffmpeg -i /home/user/preland/footage/CLIP.mp4 2>&1 | grep Duration

# Если клип < 5 секунд — использовать -stream_loop -1 для loop
# Если клип >= 5 секунд — обрезать до 5 секунд точно
```

### Шаг 4 — После рендера записать в журнал
Добавить использованный клип в таблицу "ЖУРНАЛ ИСПОЛЬЗОВАННЫХ КЛИПОВ" выше.
Обновить этот файл через Edit.
