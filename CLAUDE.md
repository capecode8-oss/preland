## 🏆 ДОКАЗАННЫЕ ПАТТЕРНЫ ХУКОВ — СЕНТЯБРЬ 2026 (из реальных данных)

### ✅ РАБОТАЕТ — проверено просмотрами

**#1 — COMMAND INTERRUPT + ФИЗИЧЕСКАЯ УГРОЗА СМЕРТИ** ← ПОБЕДИТЕЛЬ (471K на нашем аккаунте)
```
"Never [УНИВЕРСАЛЬНОЕ ДЕЙСТВИЕ] / Like This [МЕСТО]. / It Can Kill You."
```
- Условие: действие должно быть НОРМАЛЬНЫМ — то что все делают не задумываясь
- Угроза: ФИЗИЧЕСКАЯ (смерть, болезнь, вред телу) — НЕ финансовая
- Примеры залетевших: "Never Sleep Like This On A Plane" (471K наш), план-хак с ремнём (21.3M TikTok)
- Триггеры: T1 SURVIVAL + T4 PATTERN BREAK (визуал норм, текст — опасность)
- ⛔ НЕ работает: финансовые угрозы (USB порты, QR коды, такси) → люди рационализируют "со мной не случится"

**#2 — INSIDER REVEAL + ФИЗИЧЕСКАЯ УГРОЗА**
```
"Never [ДЕЙСТВИЕ] / [МЕСТО]. / A [АВТОРИТЕТ] Explained Why."
```
- Авторитет: doctor / flight attendant / crew member / security agent — реальные профессии
- Пример: "Never Swim In A Cruise Ship Pool. A Doctor Explained Why."
- Триггеры: T1 SURVIVAL + T3 STATUS ("они знают, ты нет")

**#3 — CONFESSION / FLOP-CORE** (высокий DM-send rate 2026)
```
"I [сделал X] for [Y лет / раз]. / [Инсайдер] told me [шокирующий факт]. / I [изменил поведение] since."
```
- Работает потому что: люди устали от советов успешных → "мне тоже так было" → пересылают
- Пример: "I paid $340 for a hotel room. The front desk agent told me I could've paid $80. She showed me how."
- Триггеры: T1 + T5 CURIOSITY GAP

**#4 — PATTERN BREAK (визуал + текст-противоречие)**
```
Визуал: человек делает НОРМАЛЬНОЕ, привычное действие
Текст: это ОПАСНО / неправильно / убьёт тебя
```
- Мозг получает противоречие → физически не может пролистнуть
- Ключ: визуал должен выглядеть ИДЕАЛЬНО нормально (спящая женщина у иллюминатора)

### ❌ НЕ РАБОТАЕТ — сентябрь 2026

- **Финансовые предупреждения без личной истории** (USB, QR, такси) → 124-187 просмотров
- **"5 tips / Never do these 5 things"** — список без истории → алгоритм видел миллиарды раз
- **Generic warnings без конкретного места/цифры/инсайдера** → нет доверия
- **COMMAND INTERRUPT без угрозы здоровью** → рационализация = скролл

### 🔑 УНИВЕРСАЛЬНОЕ УСЛОВИЕ ДЛЯ ЛЮБОГО ХУКА (сентябрь 2026)

Хук работает ТОЛЬКО если тема:
1. **Универсальная** — касается КАЖДОГО кто летит / едет в отель / на круиз (не "некоторых туристов")
2. **Физическая угроза** — телу, здоровью, жизни (не кошельку)
3. **Неочевидная** — не "не ходи в тёмный переулок", а то что люди делают КАЖДЫЙ РАЗ думая что это безопасно
4. **Инсайдер подтверждает** — доктор / стюардесса / шеф / офицер безопасности знает то что ты не знаешь

**FFMPEG команда с музыкой:**
```bash
FFMPEG=/usr/local/lib/python3.11/dist-packages/imageio_ffmpeg/binaries/ffmpeg-linux-x86_64-v7.0.2
MUSIC=$(ls /home/user/preland/music/*.mp3 | shuf -n 1)

```
